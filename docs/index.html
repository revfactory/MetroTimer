Features

하나에 집중한 도구

▲

Always On Top

다른 창 위에 항상 떠있습니다. 모든 데스크탑 스페이스에서 표시되어 어떤 작업 중에도 시간을 확인할 수 있습니다.

⏱

센티초 정밀도

1/100초 단위의 정밀한 시간 측정. HH:MM:SS.cc 포맷으로 시간, 분, 초, 센티초를 한눈에 파악합니다.

■

Metro Design

Windows Metro UI에서 영감받은 플랫 디자인. 다크 배경, 볼드 타이포그래피, 강렬한 액센트 컬러.

✨

Pulse Animation

1분이 경과할 때마다 배경 플래시와 스프링 바운스 애니메이션으로 시간의 흐름을 직관적으로 알려줍니다.

◼

Compact & Draggable

320x70 픽셀의 컴팩트한 가로형 디자인. 화면 어디든 드래그하여 원하는 위치에 배치하세요.

◎

Semi-Transparent

반투명 배경으로 뒤의 콘텐츠가 살짝 비쳐 보입니다. 둥근 모서리의 세련된 외관.
